# Curated Conversations

400 real customer-service interactions across 4 datasets, all in the same schema — see `curated/SCHEMA.md`. Pick whichever source suits what you want to build.

Raw data only: no commentary, scoring or tagging anywhere in the set. Generated by `curated/build/build_curated.py` — **do not edit by hand.**

| Dataset | Count | Channel | Licence | Committed | Readable rendering |
|---|---|---|---|---|---|
| HarperValleyBank | 100 | voice | CC BY 4.0 | yes | [`conversations-harpervalleybank.md`](conversations-harpervalleybank.md) |
| ABCD | 100 | chat | MIT | yes | [`conversations-abcd.md`](conversations-abcd.md) |
| AppTek | 100 | voice | CC BY-SA 4.0 | local only | [`conversations-apptek.md`](conversations-apptek.md) |
| twcs | 100 | social | CC BY-NC-SA 4.0 | local only | [`conversations-twcs.md`](conversations-twcs.md) |

**Committed** means the source licence permits redistribution, so the JSON is in `conversations/` in this repo. *Local only* means share-alike terms conflict with this repository's CC BY 4.0, so those land in `conversations-local/` (gitignored) — run the build yourself after downloading the sources.

## What each dataset gives you

| | Agent id | Customer record | Per-turn timing | Gold + machine transcript | Real dates |
|---|---|---|---|---|---|
| HarperValleyBank | yes | yes (write) | milliseconds | **yes** | 4 days only |
| ABCD | no | yes (read) | no | no | no |
| AppTek | yes | no | seconds | no | no |
| twcs | ~35% | no | message timestamps | no | **yes, 3 months** |

## Conversations per agent

Selected by agent volume: the busiest agents, up to 10 conversations each. Enough per agent to look at one person's conversations together, and enough agents to compare. *Available* is how many that agent has in the full dataset — raise `max_per_agent` in `build/manifest.json` to pull more.
